# 종로 지물포의 봄

초등학교 5학년 국어 「추론하며 읽기」 단원을 위한 읽기 게임입니다. 1918~1923년 경성 종로를 배경으로, 신문 제목·쪽지·편지를 읽으며 추론하는 힘을 기릅니다.

- 게임: `index.html`
- 선생님 화면(우리 반 연결, 답 읽기·채점): `teacher.html`
- 우리 반 답을 내 구글 시트로 받는 방법: `docs/우리 반 연결 안내.pptx`
- AI에게 답을 살펴보게 하는 프롬프트: `docs/AI 검수 프롬프트.md`

게임 속 「실제 자료」는 그때 쓰인 글을 고치지 않고 실은 것이고, 출처는 게임의 「출처 모아 보기」에 있습니다. 주인공과 가족, 가게, 길에서 만나는 사람들은 지어낸 것입니다.
